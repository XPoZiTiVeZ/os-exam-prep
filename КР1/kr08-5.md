# Задача: обработка односвязного списка строк

## Условие

Дано определение типа звена односвязного списка строк:

```c
struct Node
{
    struct Node *next;   /* указатель на следующее звено в списке */
    char *elem;          /* указатель на C-строку в динамической памяти */
};
```

Написать функцию:

```c
struct Node *process(struct Node *list, const char *str);
```

Функция должна обрабатывать список по следующим правилам:

- Если строка в поле `elem` текущего звена списка **равна** строке `str`, текущее звено удаляется, и обработка переходит к следующему звену списка.
- Если строка в поле `elem` лексикографически **больше** строки `str`, то строка в поле `elem` и строка `str` меняются местами, и обработка переходит к следующему звену списка.
- Если строка в поле `elem` лексикографически **меньше** строки `str`, то обработка переходит к следующему звену списка.

При удалении звена должна освобождаться память, занимаемая строкой. Функция принимает указатель на начальное звено в списке и должна возвращать указатель на начальное звено после удаления. В списке нет заглавного звена. Поле `elem` узлов списка и параметр `str` никогда не равны нулевому указателю.

На проверку сдаётся только функция `reorder_list` и необходимые для неё директивы `#include`. Определение структуры `Node` и функция `main` из сдаваемого на проверку файла должны быть удалены или закомментированы.

> **Примечание:** в тексте условия на фото сдаваемая функция названа `reorder_list`, а в заголовке функции указано имя `process`. Это несоответствие есть в самой задаче — уточните, какое имя ожидает проверяющая система.

## Пример

Для списка `{ "a", "b", "c", "c", "d", "c", "b", "d" }` и строки `"c"` результатом работы функции должен быть список `{ "a", "b", "c", "c", "b" }`.
