# Problem kr15-1: КР №2, задача 1

## Условие

Вам дана небольшая программа, работающая с данными в формате JSON, и файл с тестовыми данными (архив с материалами прилагается к задаче).

Программа состоит из файлов `main.c`, `cJSON.c`, `cJSON.h`. Файл с тестовыми данными называется `data.json`. Программа считывает данные со стандартного потока ввода.

Напишите и сдайте программу на языке C, которая считывает со стандартного потока ввода два целых числа `m` и `n`. Ваша программа должна вывести на стандартный поток вывода последовательность команд отладчика `gdb`, чтобы распечатать значение `value[m]` при `n`-м вызове функции `parse_object` в программе, описанной в начале задачи. Здесь `value` — это имя объекта в отлаживаемой программе, а `m` и `n` — это числа на входе вашей программы.

Отладчик `gdb` будет запускаться в каталоге, в котором находятся и исполняемый файл отлаживаемой программы, и файл с тестовыми данными, с помощью команды `gdb ./main`.

Чтобы отключить запрос подтверждения, первой командой в вашем выводе должна быть `set confirm off`. Непосредственно перед выводом значения в отладчике выполните команду `print "===The value is below==="`. В конце команд отладчика завершите его работу.

## Формат вывода

Примерный вывод программы должен быть таким:

```
set confirm off
# здесь должны быть команды, необходимые, чтобы попасть в требуемое состояние
print "===The value is below==="
# вывод требуемого значения
exit
```
