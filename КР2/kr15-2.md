# Задача: модельная файловая система FAT12

## Условие задачи

Программе в аргументах командной строки задаются имя бинарного файла, содержащего модельную файловую систему, и размер блока устройства `BS` (32 ≤ `BS` ≤ 131072).

Размещение файлов в блоках данных определяется таблицей размещения файлов FAT12. В ней под информацию о каждом блоке данных файловой системы отводится 12 бит, то есть два блока кодируются тремя байтами:

- младшие 8 бит информации о первом блоке данных находятся в первом байте;
- старшие 4 бита информации о первом блоке данных находятся в младших 4 битах второго байта;
- младшие 4 бита информации о втором блоке данных находятся в старших 4 битах второго байта;
- старшие 8 битов второго блока данных находятся в третьем байте.

Размер блока устройства равен размеру блока данных файловой системы.

В модельной файловой системе суперблок отсутствует, таблица FAT хранится в одном экземпляре в самом начале устройства и занимает целое число блоков устройства. Блоки данных размещаются непосредственно после FAT, причем первый блок данных, находящийся непосредственно после FAT, в самой FAT кодируется номером 2. То есть записи с номерами 0 и 1 в FAT не используются. Блоки устройства нумеруются от 0.

В самой таблице FAT:

- номер блока `0` означает свободный блок;
- номера блоков, начиная с `2`, используются для хранения данных;
- номер блока `0xFFF` обозначает последний блок в цепочке блоков;
- номера блоков `0xFF0` – `0xFFF` не используются для кодирования блоков файла.

Память в таблице FAT выделена для всех 4096 записей о блоках, то есть её размер всегда равен 2^12 · 12 / 8 = 6144 байта. Таблица FAT всегда корректна.

## Что нужно сделать

Ваша программа должна обработать запросы к файловой системе, вводимые на стандартном потоке ввода. Каждый запрос состоит из двух чисел `B0` и `OFFSET`:

- `B0` — номер блока в FAT (номера блоков файлов в FAT начинаются с 2);
- `OFFSET` — смещение от начала файла в байтах.

Для каждого запроса на стандартный поток вывода выведите номер блока на устройстве, на котором размещается байт с указанным смещением в файле. Если длина файла меньше запрошенного смещения, выведите `-1`.
