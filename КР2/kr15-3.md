# Задача: сумма чисел из base-кодированного файла

## Условие

В аргументах командной строки передаются путь ко входному файлу `FILE1`, путь к выходному файлу `FILE2` и опция формата `FORMAT`.

Входной файл должен быть декодирован, а выходной файл закодирован с помощью команды `basenc` с опцией `FORMAT`.

Например, если `FORMAT` равен `--base64`, то команда

```
basenc --base64
```

закодирует данные на стандартном потоке ввода и выведет результат на стандартный поток вывода.

Команда

```
basenc --decode --base64
```

декодирует данные со стандартного потока ввода и выведет результат на стандартный поток вывода.

Напишите программу, которая декодирует входной файл `FILE1`, выполнит сложение 64-битных знаковых целых чисел, находящихся в нём, и запишет закодированный результат в файл `FILE2`.

- Переполнение целых чисел при сложении игнорируется, то есть в результате сохраняются 64 младших бита.
- Результат сложения должен быть выведен в десятичной системе счисления, после него должен быть выведен символ перехода на новую строку.
- Если декодированный файл не содержит чисел, сумма равна 0.

## Ограничения

- Запрещается использовать `system`, `popen`, `/bin/sh`.
- Запрещается создавать временные файлы.
- Для запуска программы `basenc` на выполнение используйте системный вызов `execlp`.

## Пример

Входной файл в формате `--base64`:

```
MQoyCjMKNAo1CjYKNwo=
```

декодируется в:

```
1
2
3
4
5
6
7
```

результат суммирования для него:

```
28
```

который кодируется в выходной файл:

```
MjgK
```
